# Schedule App

A web application for students to manage their class schedules, supporting both recurring weekly classes and one-off temporary sessions.

## Language

**Student**:
A user who views and manages their own class schedule.
_Avoid_: User, pupil, learner

**Regular Class**:
A recurring class that repeats every week on the same day(s) and time.
_Avoid_: Recurring event, standard class, normal class

**Temporary Class**:
A one-off class session that does not repeat, such as extra lessons or seminars.
_Avoid_: Ad-hoc class, special event, one-time event

**Class Session**:
A single scheduled occurrence of a class, defined by subject, teacher, room, time, and day(s).
_Avoid_: Event, appointment, meeting

**Weekly Calendar**:
A grid view displaying 7 days × hours, showing all classes for a given week.
_Avoid_: Week view, schedule grid

**Conflict**:
When two or more class sessions overlap in time on the same day.
_Avoid_: Overlap, collision, clash

**Week Cancellation**:
Skipping a regular class for a specific week without affecting other weeks.
_Avoid_: Skip, absence, week-off

**Settings Page**:
A separate page for editing class details (subject, teacher, room, time, day) or deleting a class.
_Avoid_: Config page, edit page, admin page
